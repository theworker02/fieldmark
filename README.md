# fieldmark

Field HTML/Markdown mark fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/fieldmark/

## Install / run

```bash
git clone https://github.com/theworker02/fieldmark.git
cd fieldmark
node src/cli.js
node --test
```
